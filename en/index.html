Complete automation for high-volume production

Thermoforming machine with programmable PLC for complete cycle automation. Dedicated diagnostic system for real-time heating element monitoring. Optimised for continuous high-volume production with repetitive cycles.

How it works

How the Diagnostic System Works

A dedicated electronic board works in synergy with the PLC. It constantly monitors every heating element and, in case of failure, identifies which component needs replacing.

01

Continuous and Autonomous Monitoring

The diagnostic board checks every heating element in sequence with regular cycles. It works in the background without interfering with production: while the machine produces, the system monitors the health status of the components.

The advantage: The machine runs at full capacity while diagnostics work in parallel. No slowdowns, no interruptions for checks.
02

Fault Detection

When a heating element shows anomalies, the system detects it and signals the problem on the display. No manual diagnosis: the identification code of the faulty component appears automatically.

The advantage: The longest and most complex phase is eliminated: fault finding. The technician immediately knows what is broken without dismantling, measuring or testing components.

Technology

Technological Innovation

Three unique features that set our thermoforming machines apart

01

Dual-System Architecture

PLC dedicated to operational control and a separate electronic board for diagnostics. Two independent systems working in parallel without interference.

02

Unique Dedicated Board

The only machine on the market with separate electronics solely for heating element monitoring. Does not overload the PLC and guarantees total system reliability.

03

Simplified Maintenance

No specialist technician required. Anyone can read the code on the display and replace the indicated component by following the instructions.
